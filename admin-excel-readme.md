# Administrador de Excel

Disponible únicamente para perfiles administradores dentro del panel lateral.

## Funciones

1. Descargar la base activa en formato XLSX.
2. Seleccionar un archivo XLS o XLSX.
3. Validar estructura, campos obligatorios, coordenadas, duplicados NIT+sucursal, vendedores y coherencia zona/macrozona.
4. Comparar registros nuevos, modificados, sin cambios y ausentes.
5. Descargar la base validada.
6. Aplicar la base validada temporalmente en la sesión del navegador.

La aplicación temporal no publica los cambios para otros usuarios. La publicación permanente requiere regenerar y publicar la base integrada del sitio.
